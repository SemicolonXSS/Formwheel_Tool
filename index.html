🔐 비밀번호 생성기

-

📝 메모장

이 브라우저에 자동 저장됩니다.

✅ 체크리스트

할 일을 추가하고 완료한 항목을 체크하세요.

📏 단위 변환

길이, 무게, 온도를 간단하게 변환합니다.

-

📅 날짜 계산

두 날짜 사이의 날짜 수를 계산합니다.

-

📆 D-Day

목표 날짜까지 남은 날짜를 확인합니다.

-

📐 수학 도구

원의 넓이/둘레, 평균, 피타고라스 계산을 빠르게 할 수 있습니다.

-

📊 비율 계산기

A:B = C:D에서 미지수를 계산하거나 퍼센트를 구합니다.

-

🎨 색상 도구

색을 선택하면 HEX와 RGB 값을 확인할 수 있습니다.

HEX #4f46e5 · RGB 79, 70, 229

🔤 텍스트 도구

글자 수, 공백 제외 글자 수, 줄 수를 계산합니다.

글자 수: 0 · 공백 제외: 0 · 줄 수: 0

🌍 세계 시간

현재 브라우저 시간 기준으로 주요 도시의 시간을 표시합니다.

🎙️ 음성 변조

마이크 음성을 실시간으로 변조합니다. 브라우저의 마이크 권한이 필요합니다. (스피커로 들으면 하울링이 생기니 이어폰을 사용하세요)

60%
마이크 시작 버튼을 눌러주세요.

🎬 영상 속도 조절

영상 파일을 브라우저에서 바로 재생하면서 0.25배~4배속으로 조절합니다.

1.00×
영상을 선택하면 여기에 표시됩니다.

🎵 오디오 도구

오디오 파일을 선택해 재생 속도와 음량을 조절합니다.

1.00×
100%
오디오를 선택하면 재생할 수 있습니다.

🔳 QR 코드

텍스트나 링크를 QR 코드 이미지로 변환합니다. QR 이미지 생성 서비스가 필요합니다.

QR 코드가 여기에 표시됩니다.

🧩 JSON 도구

JSON을 보기 좋게 정렬하거나 한 줄 JSON으로 압축합니다.

JSON 결과가 여기에 표시됩니다.

🔊 텍스트 음성 변환

입력한 글을 브라우저의 음성 합성 기능으로 읽어줍니다.

1.00×
1.00
텍스트를 입력하고 읽기를 눌러주세요.

🖼️ 이미지 도구

이미지를 불러와 크기를 확인하고 원하는 크기로 PNG 파일을 만들 수 있습니다.

이미지를 선택해주세요.

🪑 자리바꾸기

셔플 전에 마우스 오른쪽 클릭으로 원하는 칸을 빈자리로 지정하세요. 지정한 빈자리에는 사람이 배정되지 않습니다.

성별을 지정하려면 남:이름 또는 여:이름 형식으로 입력하세요. 성별을 안 적은 사람은 남여 조정에서 제외됩니다.
🎨 성별 색상 ■ 남자 = 파랑 ■ 여자 = 핑크
행과 열, 사람을 입력한 뒤 셔플하세요.
